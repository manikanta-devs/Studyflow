## Chat Features

### Message Formatting
The chat supports:
- **Bold text** with `**text**`
- *Italic text* with `*text*`
- `Code snippets` with backticks
- Bullet points with `•`
- Numbered lists

### Actions
- **Send**: Enter key (Shift+Enter for new line)
- **Clear**: Removes all messages (keeps welcome)
- **Export**: Downloads chat as Markdown file

### Memory
The AI tracks:
- Topics you're interested in
- Your conversation history
- Your name (if you mention it)
- Recent subjects discussed
